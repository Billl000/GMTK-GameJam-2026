# GMTK GameJam 2026
## Theme: COUNTDOWN


A puzzle platformer game where you are inside a stopwatch counting down, and you have to dodge the incoming clock hands, as well as the terrain itself. Reach the end before the countdown ends and you’re stuck.

Assets Used:
- Kenny's 1-bit platformer pack (https://www.kenney.nl/assets/1-bit-platformer-pack)
